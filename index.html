How the work actually goes

Web, mobile, and infrastructure are one job when the shop is live. The useful version of “works under pressure” is a short list of production days, not a personality line.

Production days

Site-wide 503s from a flapping Varnish probe. PHP-FPM killed by the out-of-memory killer. A disk filling with container logs. A MariaDB upgrade on the production database VM. Each one was narrowed, changed, and left in a state the next deploy could survive.

One owner, three surfaces

A seller feature usually means a Magento module, a React screen, and a release. The mobile app consumes the same API. I stay through TestFlight with the team instead of handing the binary off at the edge of the ticket.

From scripts to Terraform

The degree was CloudFormation and Bash. At OBG the commits are Magento seller tools on the marketplace. Wamia production is Compose on Compute Engine, the seller desk is Cloud Run, Cloudflare is on the edge, and the new platform is Terraform. The tool changed. The habit is the same: the environment is part of the feature.
